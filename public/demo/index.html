¿Cómo funciona este CAPTCHA?

1. El servidor selecciona una escena de serie, película o anime.

2. Se entrega al frontend la imagen con el subtítulo incrustado y un token efímero.

3. El usuario lee la imagen y transcribe el diálogo.

4. El backend valida el texto aplicando tolerancia a tildes, mayúsculas y signos.
